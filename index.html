Case 01 · AI agent workflow

An AI agent that remembers every session

My notes system in Obsidian, run by Claude Code. Every work session starts where the last one stopped, on any device.

PythonClaude Code hooksUnit testsOpen source

Problem

AI chats forget everything when they end. I was losing decisions and repeating context every time I started a session.

What I built

  • A Python hook that runs after every AI reply and saves the session as a searchable note
  • A handoff file the agent updates after every decision
  • Weekly and monthly reviews that run on a schedule

Decisions

  • Privacy: the hook saves the conversation only. Tool output and system messages are left out.
  • Safe writes: it writes to a temp file and then swaps it in, so cloud sync never picks up a half-written note.
  • Open source: I published it for anyone to use. See Case 02.

Case 02 · Open-source tool

claude-session-saver: shipping it for everyone

I turned the hook from Case 01 into a public tool anyone can install with one command, with tests, automated CI on three operating systems, and versioned releases.

Python CLIunittestGitHub Actionspip / pipxMIT
v1.1.13 releases
25unit tests
9 / 9CI jobs passing
3OSes: Windows, macOS, Linux
0dependencies

Problem

My hook only worked in my own vault. To be useful to others it needed a real installer, safe defaults, and proof that it works on any machine.

What I built

  • A CLI: install, uninstall, backfill (import past sessions)
  • An installer that merges into existing settings, keeps a backup and never duplicates itself
  • Secret redaction: API keys, tokens, private keys and passwords become [REDACTED] before saving

Result

  • Installs from GitHub in one command; tested in a clean environment
  • Found and fixed a real bug: installed paths broke on synced folders, so I shipped a --portable mode in v1.1.0
  • Found and fixed a second bug from real use: notes scattered into subfolders when the agent changed folders. Fixed in v1.1.1 with a regression test
  • Docs: README, changelog and a security policy
